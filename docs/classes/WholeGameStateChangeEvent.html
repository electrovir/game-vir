Class WholeGameStateChangeEvent<GameState>

An event that is emitted from a GamePipeline when any part of the game state changes. Note that this will be very noisy as it will fire anything any part of the state is changed.

You probably want to use the GamePipeline.listenToState() method with a specific sub-property instead.
